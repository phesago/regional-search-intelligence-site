Privacy Policy

Last updated: October 18, 2026

Regional Search Intelligence is a locally operated research application currently under development. This policy describes its intended operation. Update this policy if the application changes.

Information accessed

With authorization, the application accesses Google Ads API keyword suggestions, search-demand metrics, geographic targeting information, and information necessary to make authorized API requests. Google OAuth provides authorization credentials used for API access.

Storage and use

The application stores OAuth authorization tokens and retrieved research results locally on the operator's computer. Tokens are used to authenticate API requests; keyword results are used for research and comparative analysis. The application does not use this website to collect account passwords or authorization tokens.

Sharing

The current application is not designed to sell or disclose Google account credentials or OAuth tokens to third parties. Requests are sent to Google's services as necessary for the authorized API functionality. Locally exported research data may be used by the operator for analysis, subject to applicable Google API terms.

Retention and deletion

The operator controls locally stored credentials, databases, and exports and can delete those files. Google account access can also be revoked from the Google account's third-party connections settings. Deleting local files does not necessarily revoke tokens already issued; revoke authorization separately when needed.

Security

Authorization files should remain on the operator's computer and must not be committed to public repositories. This public informational website does not host the application database or OAuth token files.

Changes

This policy may be updated as the application evolves. Material changes to data access or sharing practices should be reflected here before deployment.
